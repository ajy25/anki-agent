Anki Agent for Macs with Apple silicon.

Download the **`.dmg`** below, open it, and drag **Anki Agent** into **Applications**. The app includes Python; no Terminal setup is needed.

Follow the [Mac setup guide](https://github.com/ajy25/anki-agent/blob/main/docs/MAC_SETUP.md) to add your own Groq API key and choose your Anki profile and deck.

This preview is not notarized by Apple. The guide explains the per-app **Open Anyway** step if macOS cannot verify the developer.

The ZIP is an alternative app download. The JSON manifest records the version, source revision, architecture, smoke checks, and SHA-256 checksums.
